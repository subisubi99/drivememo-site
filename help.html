프로그램 안에서 F1을 누르면 더 자세한 기능 안내가 나옵니다. Press F1 in DriveMemo for the full built-in guide.

처음 시작하기

  1. 다운로드한 압축 파일을 풀고 DriveMemo.exe를 실행합니다.
  2. "구글 드라이브 폴더를 찾았습니다 … 여기에 메모를 저장할까요?"에서 예를 누르면 내 드라이브\DriveMemo에 저장됩니다.
  3. 바로 쓰면 됩니다. 입력을 멈추면 1.5초 뒤 자동 저장되고, 첫 줄이 목록의 제목이 됩니다.

다른 PC에서도 같이 쓰기

  1. 그 PC에도 Google Drive 데스크톱 앱을 설치하고 같은 구글 계정으로 로그인합니다.
  2. DriveMemo를 실행하고, 메모 폴더를 물으면 첫 PC와 같은 폴더(내 드라이브\DriveMemo)를 고릅니다.
  3. "기존 설정을 불러올까요?"에서 예를 누르면 테마·정렬·칸 폭 같은 설정도 그대로 적용됩니다.

주요 기능

쓰기

  • 자동 저장 (Ctrl+S는 즉시 저장). 메모 1개 = 텍스트 파일 1개라서 DriveMemo가 없어도 메모장으로 열 수 있습니다.
  • 실행 취소·다시 실행 (Ctrl+Z / Ctrl+Y). 되돌려도 보던 화면 그대로이고, 버튼을 길게 누르면 지난 단계 목록에서 골라 되돌립니다.
  • 찾아 바꾸기 (Ctrl+H). 글 속 링크는 짧게 클릭하면 열립니다.
  • 숫자·영문이 전각(８ｔｘｔ)으로 들어가는 입력기 문제를 막아 줍니다.

찾기와 정리

  • 전체 검색 (Ctrl+F). 한/영 전환을 잊고 쳐도, 전각 숫자(５６７７)로 쳐도 찾아 줍니다. Enter·F3로 다음, Shift+Enter로 이전 검색어.
  • 폴더: 목록 빈 곳이나 메모를 오른쪽 클릭 → 새 폴더 (Ctrl+Shift+N). 메모를 폴더 줄 위로 끌어다 놓거나 '폴더로 옮기기'로 넣습니다. 폴더째 목록 밖으로 끌어내면 안의 메모가 모두 창으로 뜹니다.
  • 즐겨찾기: 표식 칸을 클릭해 ○ △ ★ 표시. 메뉴 줄 즐겨찾기에서 표시한 메모로 바로 가거나, 즐겨찾기만 볼 수 있습니다.
  • 제목 정하기 (F2): 첫 줄 대신 원하는 제목으로 목록에 표시 (메모 내용은 그대로)
  • 정렬: 자유 배치(끌어서 순서 바꾸기) / 최종 수정순 / 작성 날짜순 / 이름순(2화 → 10화) / 자동 인식(자주 쓰는 메모 먼저)
  • 선택한 메모 합치기 (Ctrl+M): 여러 메모를 목록 순서대로 하나로. 제목은 공통점으로 자동 작성되고 txt 사본도 저장됩니다.

되돌리기

  • 변경 기록: 메모를 오른쪽 클릭 → 변경 기록. 예전 내용을 미리 보고 되돌립니다. (구글 드라이브의 메모 폴더에 함께 보관)
  • 휴지통 보기 (파일 메뉴): 지운 메모를 미리 보고 되살립니다.

보기

  • 메모를 목록 밖으로 끌어내거나 더블클릭하면 별도 창으로 뜹니다. 압정 버튼으로 항상 위 고정. [사용자 설정]으로 마음에 드는 창 모양을 기억해 두고 한 번에 맞춥니다.
  • 작업 표시줄의 DriveMemo를 오른쪽 클릭하면 띄운 메모 목록이 나옵니다.
  • [창 정렬]: 목록과 메모 칸을 고른 비율(1:1 ~ 1:5)로 정리
  • 글꼴 고르기, 글자 크기 조절 (Ctrl+휠). 모니터마다 배율이 달라도 선명하게 보입니다.
  • 밝은 / 어두운 테마, 한국어 / English, 트레이 아이콘, 윈도우 시작 시 자동 실행

그 밖에

  • 일반 txt 파일을 끌어다 놓거나 Ctrl+O로 열어서 편집 (원래 인코딩·줄바꿈 유지)
  • 보조 백업: NAS·외장 하드 등에 메모를 한 벌 더 보관 (파일 → 보조 백업 폴더 설정)
  • 프로그램 안에서 업데이트 확인, 개발자에게 의견 보내기

자주 묻는 질문

무료인가요?

네, 개인·회사 모두 무료입니다. 광고도 없습니다.

구글 드라이브가 없어도 쓸 수 있나요?

네. PC 한 대에서만 쓴다면 아무 폴더에나 메모를 저장해서 쓰면 됩니다. 여러 PC에서 같은 메모를 쓰려면 구글 드라이브가 필요합니다.

"Windows의 PC 보호" 창이 떠요.

추가 정보 → 실행을 누르세요. 개인이 만든 프로그램이라 코드 서명이 없어서 뜨는 안내이며, 처음 한 번만 뜹니다.

백신이 DriveMemo.exe를 막아요.

서명 없는 개인 제작 프로그램이라 생기는 오탐일 수 있습니다. 백신의 예외 목록에 추가하세요.

두 PC에서 같은 메모를 동시에 고치면요?

한쪽을 "충돌 사본" 메모로 따로 저장해서 어느 쪽 내용도 잃지 않습니다.

실수로 지웠거나 예전 내용으로 돌리고 싶어요.

지운 메모는 파일 → 휴지통 보기에서 되살릴 수 있습니다. 내용을 잘못 고쳤다면 메모를 오른쪽 클릭 → 변경 기록에서 예전 내용으로 되돌리세요.

휴대폰에서도 쓸 수 있나요?

지금은 윈도우 PC 전용입니다. 안드로이드판을 준비 중입니다 (테스트 빌드 완료).

영어로 쓸 수 있나요?

네. 설정 → 환경 설정 → 언어에서 English를 고르고 다시 시작하면 됩니다. 새 PC에서는 윈도우 언어로 시작합니다.

구글 드라이브 연결이 끊기면요?

계속 쓸 수 있습니다. 끊긴 동안 편집한 내용은 PC에 임시 저장되었다가 다시 연결되면 자동으로 반영됩니다.

메모는 어디에 저장되나요?

처음에 정한 메모 폴더(예: 내 드라이브\DriveMemo\notes)에 텍스트 파일로 저장됩니다. 삭제한 메모는 trash 폴더로 갑니다.

업데이트할 때 "파일이 사용 중"이라고 나와요.

DriveMemo를 완전히 종료한 뒤 다시 하세요. 트레이로 내려가 있다면 트레이 아이콘 오른쪽 클릭 → 종료.

오류 창이 떴거나 갑자기 꺼졌어요.

내용이 %APPDATA%\DriveMemo\error.log에 남고, 바로(또는 다음에 켤 때) 개발자에게 보낼지 묻습니다. 그때 보내지 않았다면 도움말 → 오류 기록 보내기로 보내 주시면 고치겠습니다. (0.14.1부터)

지우려면 어떻게 하나요?

환경 설정에서 "윈도우 시작 시 자동 실행"을 끄고, DriveMemo를 종료한 뒤 폴더를 지우면 됩니다. 이 PC 설정까지 지우려면 %APPDATA%\DriveMemo, %LOCALAPPDATA%\DriveMemo도 지웁니다. 메모 폴더는 따로 지우기 전까지 그대로 남습니다.

문의

DriveMemo 안에서 도움말 → 개발자에게 의견 보내기로 불편한 점이나 원하는 기능을 보내 주세요.

Getting started

  1. Extract the downloaded zip and run DriveMemo.exe.
  2. When it says it found your Google Drive folder and asks whether to keep notes there, click Yes. Notes go to My Drive\DriveMemo.
  3. Start typing. Notes save 1.5 seconds after you stop, and the first line becomes the title in the list.

Using it on another PC

  1. Install the Google Drive desktop app on that PC and sign in with the same Google account.
  2. Run DriveMemo and choose the same folder as on your first PC (My Drive\DriveMemo).
  3. When asked whether to load the saved settings, click Yes — theme, sort order and column widths carry over.

Features

Writing

  • Autosave (Ctrl+S saves immediately). One note = one text file, readable in any editor.
  • Undo / redo (Ctrl+Z / Ctrl+Y) that keeps your view in place. Hold the button to pick a step from the history list.
  • Replace (Ctrl+H). Links in your notes open with a short click.

Finding and organizing

  • Full-text search (Ctrl+F) that even finds Korean words typed with the English layout. Enter / F3 for the next match, Shift+Enter for the previous one.
  • Folders: right-click an empty area of the list or a note → New Folder (Ctrl+Shift+N). Drop notes onto a folder row, or use Move to Folder. Drag a whole folder out of the list to open all its notes in windows.
  • Favorites: click the mark column to set ○ △ ★. The Favorites menu jumps to marked notes or shows favorites only.
  • Set Title (F2): show your own title in the list instead of the first line (the note itself is unchanged).
  • Sort by your own drag-and-drop order, last modified, date created, name (natural order) or Smart (most used first).
  • Merge selected notes into one (Ctrl+M).

Going back

  • Version History: right-click a note → Version History… to preview and restore earlier versions (kept in your notes folder on Google Drive).
  • File → View Trash…: preview and restore deleted notes.

Viewing

  • Drag a note out of the list (or double-click it) to open it in its own window, optionally always on top. My Layout remembers a window shape you like and applies it in one click.
  • Right-click DriveMemo on the taskbar for a list of your floating notes.
  • Arrange Windows splits the list and the note at the ratio you pick (1:1 to 1:5).
  • Choose a font and zoom (Ctrl+Wheel). Stays sharp on monitors with different scaling.
  • Light and dark themes, Korean / English, tray icon, start with Windows.

More

  • Open and edit plain .txt files by dropping them in or with Ctrl+O (encoding and line endings preserved).
  • Secondary backup to a NAS, external drive, etc. (File → Set Secondary Backup Folder…)
  • In-app updates and feedback.

FAQ

Is it free?

Yes, for personal and business use. No ads.

Do I need Google Drive?

Only to share notes between PCs. On a single PC you can keep notes in any folder.

"Windows protected your PC" appears.

Click More info → Run anyway. The program has no code signature, so Windows shows this once.

My antivirus blocks DriveMemo.exe.

This is likely a false positive because the program is unsigned. Add it to your antivirus exceptions.

What if I edit the same note on two PCs at once?

One side is kept as a separate "conflict copy", so nothing is lost.

I deleted a note or want an earlier version back.

Restore deleted notes from File → View Trash…. For an earlier version of a note, right-click it → Version History….

Can I use it on my phone?

For now it runs on Windows PCs only. An Android version is in progress (test build done).

How do I switch the language?

Options → Settings… → Language, then restart DriveMemo. A new PC starts in your Windows language.

What if Google Drive is disconnected?

Keep writing. Changes are stored locally and synced when the connection returns.

It showed an error or closed suddenly.

The details are saved to %APPDATA%\DriveMemo\error.log, and DriveMemo offers to send them (right away or the next time it starts). You can also send them later with Help → Send Error Log….

How do I uninstall it?

Turn off "Start with Windows" in settings, quit DriveMemo and delete its folder. To remove this PC's settings, also delete %APPDATA%\DriveMemo and %LOCALAPPDATA%\DriveMemo. Your notes folder stays until you delete it.
