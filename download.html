설치Installation

  1. 압축을 원하는 폴더에 풉니다. (예: C:\Tools\DriveMemo) 구글 드라이브나 NAS보다는 C: 같은 로컬 디스크를 권장합니다.
  2. DriveMemo.exe를 실행합니다. 설치 과정은 없습니다.
  3. 처음 실행할 때 구글 드라이브 폴더를 찾아서 "여기에 메모를 저장할까요?"라고 묻습니다. 예를 누르면 끝입니다.
  1. Extract the zip to any folder (e.g. C:\Tools\DriveMemo). A local disk is recommended over Google Drive or a NAS.
  2. Run DriveMemo.exe. There is no installer.
  3. On first run it finds your Google Drive folder and asks whether to keep notes there. Click 예 (Yes) and you're done.
"Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요. 개인이 만든 프로그램이라 코드 서명이 없어서 뜨는 안내이며, 처음 한 번만 뜹니다.
If "Windows protected your PC" appears, click More info → Run anyway. It appears because this individually made program has no code signature, and only shows once.

준비물Requirements

  • Windows 10 또는 Windows 11 (윈도우에 기본으로 들어 있는 .NET Framework로 실행되므로 따로 설치할 것 없음)
  • 여러 PC에서 함께 쓰려면 각 PC에 Google Drive 데스크톱 앱을 설치하고 같은 계정으로 로그인. PC 한 대에서만 쓴다면 필요 없습니다.
  • Windows 10 or 11 (runs on the .NET Framework built into Windows — nothing else to install)
  • To use it on several PCs, install the Google Drive desktop app on each one and sign in with the same account. Not needed for a single PC.

업데이트Updating

DriveMemo 안에서 도움말 → 업데이트 확인을 누르면 새 버전을 받아서 바로 바꿉니다. 메모와 설정은 그대로 유지됩니다. 시작할 때 하루 한 번 자동으로도 확인합니다.

In DriveMemo, choose 도움말 (Help) → 업데이트 확인 (Check for updates) to download and install a new version. Your notes and settings are kept. It also checks automatically once a day at startup.
